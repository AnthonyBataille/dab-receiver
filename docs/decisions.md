# Project Decisions

- Use C++20.
- Use CMake with presets.
- Target Visual Studio 2022 x64.
- Use Catch2.
- Enable `/W4` and treat warnings as errors for project code.
- Use clang-format.
- Use Python 3.12 for DSP prototypes.
- Keep the backend independent of the GUI.
- Decode offline recordings before implementing live reception.
- Use short feature branches and squash merges.
- Use Conventional Commit messages.
- MIT is provisionally preferred, but licensing is deferred while the project is private.
