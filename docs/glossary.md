# DAB Glossary

**ensemble**: transmitted signal, comprising a set of regularly and closely-spaced orthogonal carriers. The ensemble is the entity which is received and processed. In general, it contains programme and data
services. 

**service**: user-selectable output which can be either a programme service or a data service.

**service component**: part of a service which carries either audio (including PAD) or data.

**Common Interleaved Frame (CIF)**: serial digital output from the main service multiplexer which is contained in the
**Main Service Channel** part of the transmission frame.

**Capacity Unit (CU)**: smallest addressable unit (64 bits) of the Common Interleaved Frame (CIF).

**logical frame**: a 24 ms data unit contributing to one subchannel; five consecutive logical frames transport one DAB+ audio superframe.

**sub-channel**: part of the Main Service Channel which is individually convolutionally encoded and comprises an
integral number of Capacity Units per Common Interleaved Frame.

**access unit**: access unit contains the audio samples for 20 ms, 30 ms, 40 ms or 60 ms of audio depending on the
sampling rate of the AAC core, respectively 48 kHz, 32 kHz, 24 kHz or 16 kHz.

**audio super frame**: audio super frame contains a number of AUs which together contain the encoded audio for 120 ms.
