# Project Scope

## MVP

- Windows application.
- RTL-SDR Blog V3-compatible device.
- DAB+ Band III, Mode I.
- Manual DAB block selection.
- Ensemble synchronization and service discovery.
- Selection and playback of one DAB+ audio service.
- Basic GUI controls.
- Offline IQ decoding before live decoding.
- C++ backend with CMake.
- Python for DSP experiments.
- GUI technology deferred.

## Non-goals

- DAB modes II-IV.
- L-band.
- Legacy DAB audio.
- Automatic scanning.
- Multiple services.
- Data services.
- A polished GUI.
- Operating systems other than Windows.
- Early optimization.
